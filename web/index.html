How it works

  • 01Aegis watches every file create / modify / rename inside your chosen folders.
  • 02If more than 25 files change in 60 s — or any file gets a known ransomware extension — a critical alert is raised.
  • 03Suspected ransom notes (README_DECRYPT, etc.) are auto-detected via signature.
  • 04You receive a toast notification and the event is logged in the dashboard feed.
